# Support Triage Skill

Use this skill when handling CloudGrid support tickets for billing exports,
dashboard access, audit logs, and report recovery.

## Workflow

1. Identify whether the ticket includes an account id.
2. If an account id is present, use it in the response and inspect the likely
   product area.
3. If the ticket describes permissions, mention role propagation and access
   policy checks.
4. If the ticket describes exports, mention export policy and recent migration
   or retention changes.

## Output

Return a concise next action and the one missing detail, if any.
